# Hotel Management System

## Project Overview
A console-based Hotel Management System developed using Java, Hibernate ORM, and MySQL.

## Technologies Used
- Java
- Hibernate ORM
- Jakarta Persistence API
- MySQL
- Maven

## Main Features
- Customer Management
- Hotel Management
- Room Management
- Booking Management
- Payment Management
- Room Availability Tracking
- CRUD Operations
- Input Validation

## Architecture
Java Application → DAO Layer → Hibernate ORM → MySQL Database

## How to Run
1. Clone or download this repository.
2. Open the project in your Java IDE.
3. Configure your MySQL database connection.
4. Create or configure the required database.
5. Resolve Maven dependencies.
6. Run the main application class.
